# WalletConnect Example

Discover WalletConnect wallets through the `wata` directory, then connect to one.

```sh
pnpx gitpick https://github.com/wevm/wata/tree/main/examples/walletConnect walletConnect
cd walletConnect
pnpm install
pnpm dev
```

Open the app, pick a wallet, and scan the QR code (or tap the deep link on
mobile) with that wallet. The project id is a public demo id -- swap in your
own from [dashboard.reown.com](https://dashboard.reown.com).
