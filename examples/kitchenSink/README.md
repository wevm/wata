# Kitchen Sink Example

```sh
pnpx gitpick https://github.com/wevm/wata/tree/main/examples/kitchenSink kitchen-sink
cd kitchen-sink
pnpm install
pnpm dev
```

Open http://localhost:5173 for the web `postMessage` and server `webhookCallback` demos.

In another terminal, run the CLI `deviceCode` demo:

```sh
pnpm dev:cli
```
